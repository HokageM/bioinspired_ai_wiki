# Grid Cells

Neurons that **form a coordinate system for navigation** (L01).

## Biological origin

As with [[place-cells]], presented in
[[L01-introduction-to-bio-inspired-ai]] as an observed biological mechanism. No
species, region or citation is given.

## Computational form

None given in the lecture. The only functional claim is that grid cells supply a
*coordinate system* — i.e. a metric over space — where [[place-cells]] supply
*identification* of a location.

```text
# the distinction the lecture draws, as a contract:
place_cells:  position -> which place am I in?      (identity)
grid_cells:   position -> where am I, numerically?  (metric / coordinates)
combined:     comprehensive inner positioning system
```
